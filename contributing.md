## 🔧 Setup Walkthrough

### Step 1 — Workspace
Set up folders for the game, extracted files, and backups.

Unpack the game archive with the included tools.

### Step 3 — Pick a Target
Start with a texture — it's the easiest entry point.

### Step 4 — Edit

### Step 5 — Repack
Rebuild the archive and swap it into the game folder.

### Step 6 — Test
Launch the game, verify your mod, and iterate.
